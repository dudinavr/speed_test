# speed_test.py

Простой скрипт для замера скорости скачивания. Делает 10 последовательных запросов к указанному URL, ждёт каждый ответ полностью, считает среднее время запроса, объём скачанных данных и скорость в МБ/с.

## Установка

```
pip3 install requests
```

## Запуск

```
python3 speed_test.py <URL>
```

Пример:

```
python3 speed_test.py https://fsn1-speed.hetzner.com/100MB.bin
```

## Опции

- `-n`, `--num-requests` — количество запросов (по умолчанию 10):

```
python3 speed_test.py https://fsn1-speed.hetzner.com/100MB.bin -n 5
```

- `--help` — справка по аргументам:

```
python3 speed_test.py --help
```
